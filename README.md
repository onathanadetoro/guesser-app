# guesser-app

🌍 Country Guesser! 🎮
Welcome to Country Guesser! It is a fun game where you try to guess the secret country before all of its letters are shown on the screen!

🌟 How to Play
Pick a Speed: Choose how fast the letters show up!

🐢 Easy: Gives you plenty of time to think.

🏃 Medium: A little faster!

⚡ Hard: Super fast for experts!

Press Start: Click the 🚀 Start Game button.

Watch the Screen: Letters will pop up one by one.

Type Your Guess: Type the name of the country in the box and click Submit Guess.

Win and Move On: If you get it right, you move to the next round!

💡 Tips to Win!
Capital Letters: Don't forget to use a big capital letter at the start of each word (like Canada or United States).

Harder Rounds: Once you reach Round 5, the countries get much trickier! 🧠

Be Quick: Try to guess the country using as few letters as possible!
